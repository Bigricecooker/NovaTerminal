# P0 实施计划（审查修订）

依据用户提供的 P0 2.0 计划实施 A1 → A2 → A3 → B → E → F → D → C。范围为设置、终端交互、关闭与重连、标签、搜索链接和公开连接导入导出；不含自动重连、会话恢复、云服务或任意程序执行接口。

## 审查后的决策

- 实施前源码核对：主题只有内存状态、外观硬编码、大输入会关闭会话、限额固定 4，主进程没有剪贴板 / 设置 / 外链 / 连接文件入口；这些作为本次修改基线，不代表当前状态。
- 保留资产解析器现有更严格的名称 80 字符、SSH 用户名 128 字符边界；路径沿用 4096 字符，避免已有合法本地连接无法备份。导入文件上限为 1 MiB（UTF-8 字节），合并后仍经过现有资产文档大小、500 项和 8 层校验。
- 退出请求采用请求编号与界面应答：5 秒限制界面接收响应，不限制用户考虑时间；确认显示后持续探测 renderer 响应，崩溃或无响应才退出。取消不得提前清理会话。
- 主进程强制实际会话资源上限（含正在回收的进程），renderer 强制保留标签上限；已结束标签仍计入标签数。清理期间新建可能短暂被拒绝，必须明确反馈。降低上限不终止存量会话。
- 新安装没有设置文件是正常首次启动，不提示损坏。读取失败保留原文件并提示；能恢复的损坏文件用 Windows 合法时间戳备份。保存失败保留旧内存快照。
- 外观保存后统一生效；Shell 与默认目录只影响新会话。重连使用当前资产认证引用，但端点变化或资产删除必须提示；不复用陈旧认证记录。
- A2 的剪贴板开关实际行为随 B 验收，A3 的关闭开关随 E 验收，避免把依赖未实现写成完成。
- 附件中的停止条件作为风险审查线索；无法在本机验证的平台与人工交互明确保留待验收，不把它们写成已通过。
