## 当前范围

- Electron + React + TypeScript + shadcn/ui 桌面应用，已有本地 PTY、SSH 直连、多标签、连接与分组管理、设置、终端剪贴板 / 搜索 / 外链及公开连接导入导出。
- 标签默认上限 4，可设置 1–8；后台终端保持挂载。关闭活动会话默认确认，Shell 退出后保留输出，可显式重连；刷新或退出不恢复会话、不自动重连或重放命令。
- 只维护桌面运行模式。Vite 仅为 `127.0.0.1:5180` 开发热更新提供页面；正式资源由 `app://novaterminal/` 加载，不监听 HTTP / WebSocket。
- 提供 Windows x64 可运行目录包，运行无需系统 Node.js 或 Vite。安装器、签名、自动更新、跳板机、SSH Agent、交互式多因素认证、文件传输和远端管理未实现。

## 实现决策

- 使用 npm 和 `package-lock.json`，版本范围以 `package.json` 为准。源码按 `src/main` / `src/preload` / `src/renderer` / `src/server` / `src/shared` 分层；Vite 根为 `src/renderer`，`@` 指向界面源码，`@shared` 指向共享协议。产物为 `dist/`、`out/electron/` 和 `release/`。
- renderer 保持沙箱、上下文隔离和 Node 集成关闭。系统能力经有限 preload / IPC 提供，校验来源、主框架、参数与会话归属；每个会话使用独立 utility process。安全边界以安全说明及实际实现为准。
- 同一用户数据目录在初始化存储与窗口前获取 Electron 单实例锁，重复启动退出并唤起原窗口，避免资产 / 设置快照互相覆盖。不同用户数据目录仍可独立运行。
- UI 使用官方 shadcn CLI，当前基础为 Radix / Nova，颜色使用统一 tokens，保留上游许可。在用技能位于 `.agents/skills/shadcn/`，来源记录于 `skills-lock.json`；技能目录完整保留，包括附属评测及配套资源。`components.json` 仍引用 `src/renderer/src/lib/utils.ts`，保留该兼容入口。
- 窗口无系统边框，React 绘制的按钮与应用操作共用 48px 页头、主题及布局；页头可拖动、操作区 `no-drag`。`novaWindow` 仅允许固定窗口动作和最大化状态读取 / 订阅。自绘最大化按钮不提供系统悬停贴靠菜单。
- Windows GUI 启动保留 `windowsHide: false`；桌面冒烟必须断言窗口可见且未最小化。Electron、打包工具与 esbuild 固定版本；ASAR 解包原生模块及 ConPTY 文件，升级运行时或切换平台后重新验证。
- 设置由主进程校验、原子保存，preload 初始快照在 React 前应用主题。外观修改已有 xterm options，不重建会话；Shell / 默认目录用于新建，本地资产目录优先，不可用时报错。主进程限额包含回收中的进程，renderer 标签限额包含已结束标签，降低上限不终止存量。
- 退出请求使用编号与 ACK，每秒探测，5 秒无界面响应才继续退出，不限制用户考虑时间。取消前不清理资源；开发启动器保留 Vite 至 Electron 退出。强杀、崩溃、刷新和关机不承诺确认。
- 显式重连保留标签 ID、清空旧缓冲，读取当前资产认证；SSH 端点变化或资产删除时拒绝。资产名称同步仅更新标签名称并保留 `target` 对象，避免重建会话；标签排序只保留在当前工作区。
- 输入输出使用有界缓冲、UTF-16 ACK 和背压；粘贴分块保留代理对。清屏同时取消待处理正则搜索、清理搜索装饰和选区，Ctrl+C 无选区时仍交给 Shell。普通搜索使用 SearchAddon；正则在独立 Worker 中执行，500ms 超时终止，快照最多 4,194,304 个 UTF-16 单元、每 128 行让出界面线程，内容 / 尺寸变化取消旧结果。保持 proposed API 关闭，使用稳定选区突出匹配；WebLinksAddon 和 OSC 8 共用 http/https 校验及有限主进程外链接口。

## 数据与兼容性

- 资产模型位于 `src/shared/assets.ts`，renderer 旧入口兼容导出。内部文档沿用 `novaterminal.assets.v1`，原子保存公开配置及分组展开 / 当前层级，读取失败时禁止覆盖。SSH 秘密仅由主进程系统安全存储加密保存，不向 renderer 返回；更换认证以独立引用先写新记录，公开配置失败时回滚，成功后清理旧记录。
- 资产 ID 保持稳定，可选 `credentialId` 指向认证记录，旧文档缺省使用资产 ID。最多 500 项资产、8 层分组，凭据库预留一次替换空间（501 条）。删除资产按有效引用清理认证；已建立会话不受资产删除或编辑影响。
- 每次页面加载成功读取并校验已提交资产后，主进程先按有效引用恢复凭据库，清理无引用记录及自身临时文件，再开放认证写入；同次加载不重复清理，避免误删正在保存的新记录。资产不可读 / 损坏时不清理凭据；恢复失败阻止新认证写入并提示刷新重试。
- 正式资源和开发页面的资产、加密凭据与设置存储隔离，不自动迁移；主机指纹沿用平台目录，首次须确认，变化或异常拒绝。同目录临时文件加硬链接原子发布指纹，不支持硬链接时首次信任失败关闭。
- 公开交换格式为 `novaterminal.connections` v1，文件上限 1 MiB。导出白名单排除认证、凭据引用、指纹和 UI 状态；导入预览后原子合并，同路径同名组复用，新增条目生成 ID，SSH 必须编辑补充认证。具体字段边界和存储流程见开发指南与安全说明。
- 资产列表不创建根目录或未分组容器；顶层连接与分组共用列表，分组优先、同类按创建顺序。拖放只改变父分组，校验整个子树；连接双击或 Enter / 空格打开，单击只更新当前层级。

## 验证边界

- SSH 自动化集成使用本机临时协议服务、测试密钥和人工凭据，不等同于实际远程服务器验收。
- 命令、测试职责与输入方式统一维护于 [开发指南](development.md#自动化测试)。系统 Node.js 测试进程适配仅位于 `tests/`；桌面变更运行真实 Electron 冒烟，目录包另跑 `test:package`，二者不能互相替代。
- 独立 exe 验收需显式 `--user-data-dir`，以设置哨兵确认隔离，并覆盖重启恢复及损坏配置默认值 / 警告 / 备份，结束后清理临时目录。
- Electron 合成键鼠、nativeTheme 模拟、文件选择与外链替身不等同于物理输入、真实 IME 或操作系统交互。单实例、认证中断恢复及高回溯正则的可重复验证入口为 `test:recovery`；最大回滚 / 8 会话组合容量、原生文件选择、真实系统主题及启动视觉、WSL / 可选 Shell、人工拖动与贴靠、后台焦点、真实远端 SSH、macOS / Linux 仍需专项验证。
- 尚无持续集成。单次本机结果与依赖审计结果放在本地记录，不作为后续版本、全平台或全项目无漏洞的结论。
