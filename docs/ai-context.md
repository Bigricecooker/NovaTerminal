## 实现与边界

- 当前为 Electron 桌面运行时、Vite + React + TypeScript 界面，仅维护桌面运行模式。已有本地 PTY、SSH 直连、多标签、SSH / 本地目录资产、分组 / 搜索及深浅主题。
- 本地 / SSH 默认共用 4 标签上限，可设置 1–8；后台会话保持挂载。关闭活动会话默认确认，仅清理所属会话；Shell 自行退出后保留标签，可显式重连。
- renderer 会话创建延迟至微任务并检查是否已销毁，避免开发期重复挂载预占额外名额；异步创建完成前关闭的会话在取得 ID 后立即释放。
- SSH 首次主机指纹须明确确认，变化或记录异常时拒绝；不自动重连或重放命令。公开资产仅持久化连接配置（包含本地起始目录）。侧栏“添加连接”统一填写一次 SSH 认证信息，支持仅保存 / 保存并连接，秘密由系统安全存储加密保存；右上角只保留快速本地终端入口。
- 已提供 Windows x64 可运行目录包，包含运行时，不依赖 Vite 或系统 Node.js；安装器、签名和自动更新未实现。
- 资产支持分组 / 连接重命名、跨分组移动、带确认的子树删除和右键菜单；SSH / 本地连接可编辑名称、分组、端点 / 认证或起始目录。公开配置支持 JSON 导入 / 导出；跳板机、SSH Agent、交互式多因素认证、文件传输和远端管理未实现。

## 技术决策

- 使用 npm 和 `package-lock.json`，Node.js / npm 版本范围以 `package.json` 为准。安装使用 `npm ci`。
- 源码按 `src/main` / `src/preload` / `src/renderer` / `src/server` / `src/shared` 分层。Vite 根目录为 `src/renderer`，界面源码位于 `src/renderer/src`；`@` 指向界面源码，`@shared` 指向跨进程协议。构建产物为 `out/electron/` 和仓库根目录 `dist/`。
- UI 使用 shadcn 官方 CLI，当前基础为 Radix / Nova；统一主题 tokens，保留上游源码与许可。`.agents/skills/shadcn/` 为在用协作技能，来源由 `skills-lock.json` 记录。
- `components.json` 的工具别名仍引用 `src/renderer/src/lib/utils.ts`，保留此兼容入口。字体从依赖包本地分发。
- 桌面使用沙箱 renderer、受限 preload、校验来源 / 主框架 / 参数 / 归属的 IPC，以及每会话 utility process。PTY / SSH 的核心工作进程共用；原生代码不进入前端包。
- `npm run dev` 启动桌面和 `127.0.0.1:5180` 热更新页面，保留 Electron DevTools 调试。独立浏览器运行模式、WebSocket 终端服务、`dev:web` 和 `preview` 已移除；开发和构建后的应用共用 preload / IPC / utility process。普通浏览器打开页面仅提示使用桌面应用。
- Windows GUI 启动必须保持 `windowsHide: false`，避免首次显示被隐藏；桌面冒烟检查窗口可见且未最小化，不能仅依赖页面加载、进程或截图成功。
- 桌面使用无系统边框窗口，三个窗口按钮与应用操作共用 48px React 页头、主题及布局，不再使用原生 Window Controls Overlay 或颜色同步 IPC。页头可拖动，操作组为 `no-drag`；受限 `novaWindow` 仅提供固定窗口操作及最大化状态读取 / 订阅，校验来源、主框架和动作白名单。
- 顶栏下方使用全宽 Separator；应用操作与窗口按钮之间设置贯穿顶栏高度的竖分割线。终端标签下直接显示输出区域，不设清屏工具栏；Shell 与连接状态集中在底部状态栏。
- 桌面构建通过 `app://novaterminal/` 加载包内资源，设置 CSP 并禁止外部导航和页面权限；不监听 HTTP / WebSocket。Vite 仅在开发期提供回环热更新页面，静态 `dist/` 无法独立提供终端。`ws` 仅为开发 / 目录包测试依赖。
- Electron、打包工具和 esbuild 固定版本；ASAR 解包原生模块及 ConPTY 所需文件。新增运行时保留 Electron / Chromium 许可；更换平台或原生依赖时重新验证。
- 桌面正式资源和桌面开发站点资产 / 加密凭据 / 设置存储隔离，不自动迁移；主机指纹沿用已有平台目录。旧浏览器站点存储不自动读取。
- 设置由主进程校验和原子保存，初始 preload 快照在 React 前应用主题；外观即时更新已有 xterm，不重建会话。Shell 枚举和默认目录只影响新建，本地资产目录优先，不可用时报错不回退。主进程实际资源计数含正在回收进程，renderer 标签计数含已结束标签；降低上限不清理存量。
- 退出请求统一编号与 ACK，每秒探测，5 秒界面无响应才继续退出；不限制用户考虑时间，取消前不清理资源。开发启动器等待 Electron 决定并保持 Vite，取消允许再次请求。强杀 / 崩溃 / 刷新 / 关机不承诺确认。重连沿用标签 ID 并清空缓冲，读取当前资产认证，端点变化或已删除时拒绝，不自动重放。
- 终端右键菜单提供复制 / 粘贴 / 全选 / 清屏 / 搜索。剪贴板主进程限制复制 1,048,576、粘贴 65,536 个 UTF-16 单元，多行确认只显示统计；超限不终止会话。清屏同时清除搜索装饰与选区，避免不可见选区拦截 Ctrl+C。Ctrl+C 无选区仍交给 Shell，快捷键避开表单、弹窗与 IME 合成。
- SearchAddon 使用稳定选区突出当前匹配，保持 proposed API 关闭，支持正则 / 大小写与前后搜索。WebLinksAddon / OSC 8 统一验证 http/https，经有限主进程 API 打开外部浏览器，页面外部导航仍禁止。
- 资产模型位于 `src/shared/assets.ts`，renderer 旧入口兼容导出。公开配置传输为 `novaterminal.connections` v1，文件最多 1 MiB；沿用名称 80、用户名 128、目录 4096、500 项 / 8 层及资产文档大小限制。白名单导出不含认证、凭据引用、指纹或 UI 状态；导入预览后原子合并，同路径同名组复用，新增生成 ID，SSH 必须编辑补充认证。保存失败保留原文档。
- 资产沿用 `novaterminal.assets.v1`，同一文档内原子保存资产及分组 ID 形式的展开 / 当前层级状态；旧文档未记录展开状态时默认折叠。新增仅在所属分组等于当前层级时展开对应分支，搜索展开不覆盖保存状态，保存失败不更新界面。
- 不设“根目录”或“未分组”节点 / 容器；`parentId: null` 的连接与顶层分组共用列表，分组文件夹优先、同类按创建顺序排序。列表空白处可选中顶层或作为顶层拖放目标。工具栏添加 SSH 默认“未分组”，右键分组添加则预选触发分组，均可手动调整。本地连接通过受限 `novaDirectories` 系统目录选择器创建，保存成功后打开设置选定的 Shell；会话协议只允许有界绝对目录，会话进程检查真实目录，失效时显示错误。
- 资产拖放只变更父分组，沿用分组优先、同类按创建顺序的排序；校验循环和整个子树深度。右键菜单使用 shadcn / Radix ContextMenu 定位和键盘交互，移动对话框提供非拖拽操作，删除子树使用 AlertDialog 确认。
- 资产连接单击仅更新当前分组层级；双击 SSH / 本地连接直接打开终端，认证弹窗已删除。Enter / 空格提供等效操作并忽略按键重复；分组和新建入口仍单击操作。
- SSH 凭据由主进程通过 `safeStorage` 加密保存在用户数据目录，拒绝不可用密钥库及 Linux `basic_text` / 未知后端。仅暴露保存 / 删除 API，后续会话发送有效凭据引用和公开端点，主进程校验归属及端点后解密，不向 renderer 返回秘密。编辑默认保留认证，端点变化需重新填写；更换认证先创建独立记录，资产 ID 不变，可选 `credentialId` 指向新记录（旧文档缺省使用资产 ID）。公开资产保存失败清理新记录，成功清理旧记录；删除资产按有效引用清理。记录最多 501 条，为 500 项资产预留一次替换空间；缺失或失效可通过编辑补充认证。
- 侧栏 SSH 连接悬停显示用户名@主机，本地连接悬停仅显示完整起始目录路径，会话标签显示连接名称；编辑和重命名保存成功后按稳定资产 ID 同步关联标签名称。标签名称更新保留会话 `target` 对象和终端挂载，不自动重连；新端点 / 认证 / 本地目录仅影响新会话。
- 顶部会话标签仅支持左右排序，不新增分组；拖动和 Ctrl+Shift+方向键保留活动标签、会话身份及已挂载终端。标签只含公开引用，顺序仅保留在当前工作区，刷新仍关闭会话，不自动重连。
- 输入输出保持有界缓冲、UTF-16 ACK 和背压；资源限额以共享协议及服务实现为准。
- 粘贴分块保留完整 UTF-16 代理对，避免 PTY / SSH 分别编码输入时破坏 emoji。主机指纹通过同目录临时文件和硬链接原子发布，不覆盖已存在记录；独立会话同时确认相同指纹可成功，不同指纹竞争或异常记录仍拒绝。文件系统不支持硬链接时首次信任失败关闭。
- Git 初始分支为 `main`；提交规范集中维护于贡献指南，尚未配置提交钩子。实际提交与远端状态以 Git 为准。

## 验证要求与待覆盖范围

- 事实核验与结论的统一要求见 [协作规则](../AGENTS.md#事实核验与结论)，本文件不重复维护。

- 自动化覆盖资产、标签、桌面会话链路下的真实 PTY / 临时 SSH、来源 / 协议、背压、桌面开发页面、窗口动作白名单、独立指纹存储并发及 Unicode 输入分块；具体命令和覆盖见开发指南。系统 Node.js 测试进程适配仅位于 `tests/`。
- 桌面变更需运行真实 Electron 冒烟；目录包需单独运行 `test:package`，不能用系统 Node.js 测试或开发 Electron 代替独立 exe 验收。
- 独立 exe 验收显式传 `--user-data-dir` 并预置设置哨兵验证隔离，不能仅依靠 APPDATA 环境变量；覆盖完全退出后重启恢复偏好，以及损坏配置后的默认值、警告与原文件备份；测试完成清理临时目录。
- `test:p0` 覆盖真实 Electron / PTY 下的设置、最小布局、快捷键、搜索、文本剪贴板、重连、导入回滚及退出去重 / 取消；系统主题通过 nativeTheme 模拟，文件对话框与外链使用测试替身。设置、URL、导入和退出状态机另有边界单元测试；不能将这些结果等同于真实 IME 或系统浏览器交互。
- `test:acceptance` 补充 Windows 下 Electron 键鼠输入驱动的拖选复制、真实命令 Ctrl+C 中断、清屏清选区、右键 Unicode 粘贴、搜索方向 / 正则、鼠标报告模式下的链接修饰键和 Shell / 目录边界。可选系统浏览器检查经正式 IPC 启动默认浏览器并确认回环请求；可选 WSL 只记录观测，不自动判为通过。输入方式、环境开关与限制见开发指南。
- `test:sidebar` 通过真实 Electron 鼠标发起拖拽及调试协议交付拖放，覆盖展开恢复、工具栏 / 分组菜单新增范围、连接编辑 / 刷新恢复 / 端点认证校验、本地目录编辑、标签名称同步、搜索、子树移动、菜单边界、重命名、删除确认、存储失败和运行会话标签移动；`test:desktop` 覆盖真实 SSH 编辑免填重连与认证替换失败回滚。使用独立临时配置，不读写个人资产。
- 窗口按钮鼠标输入和最大化状态同步由 Electron 冒烟覆盖；人工鼠标拖动、系统贴靠、后台 xterm 输出 / 焦点、真实远端 SSH 和 macOS / Linux 兼容性仍需专项验证。自绘最大化按钮不提供原生悬停贴靠菜单。
- 尚无持续集成；本机单次通过记录不作为其他平台或后续改动的验收结论。
- 依赖审计按开发指南执行；不将运行依赖审计通过描述为全项目无漏洞。
