# NovaTerminal

本地运行的 SSH 与终端客户端，采用 React、TypeScript 和 shadcn/ui 构建。

项目处于开发阶段，当前提供浏览器界面和本机 Node.js 会话服务，尚未提供桌面安装包。Windows 已完成本地验证；macOS 和 Linux 尚未验证。

## 功能

- **独立终端**：本地 Shell 与 SSH 共用多标签工作区，最多 4 个标签；切换保留会话和输出，关闭释放所属连接。
- **SSH 直连**：支持密码、私钥及加密私钥认证；首次连接需确认 SHA-256 主机指纹，已记录的指纹变化时拒绝连接。
- **连接管理**：创建连接与嵌套分组，按名称、主机、端口或用户名搜索；连接参数保存在当前浏览器站点，不含认证凭据。
- **终端显示**：支持 Unicode、ANSI、键盘输入、粘贴、尺寸同步、清屏及深浅主题。

当前不支持跳板机、SSH Agent、交互式多因素认证、凭据保存、文件传输或远端监控。连接配置暂不支持编辑、删除、导入或导出。

## 快速开始

环境要求：Node.js `>=24.19.0 <25`、npm `>=11.19.1 <12`。

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:5173/>。端口被占用时服务会报错，请先确认占用来源。

本机服务具有当前系统用户的 Shell 权限。仅在本机运行，保持默认回环监听地址，不要通过反向代理、端口转发或公网地址暴露服务。完整边界见 [安全说明](SECURITY.md)。

### 本地终端

点击右上角“新建本地终端”。Windows 启动不加载用户 profile 的 PowerShell；macOS / Linux 使用环境变量 `SHELL` 指定的 Shell，未设置时使用 `/bin/sh`。初始工作目录为用户主目录。

关闭标签会移除对应输出；Shell 自行退出后保留标签供查看。刷新页面或停止服务会断开会话，终端输出不持久化。主题选择仅在当前页面有效。

### SSH 连接

1. 点击“连接 SSH 服务器”，填写主机、端口和用户名。主机只填写域名或 IP，不包含 `ssh://`、用户名或路径。
2. 选择密码认证，或粘贴完整私钥及可选口令。认证信息仅用于当前连接，每次新建连接需重新填写。
3. 首次连接时，通过可信渠道向服务器管理员核对 SHA-256 指纹，再选择“信任并连接”。
4. 连接成功后在对应标签操作。清屏仅清理显示，不向远端发送清屏命令。

指纹变化或记录无法安全读写时连接会被阻止。记录位置与主机密钥变更处理见 [SSH 主机信任](SECURITY.md#ssh-主机信任)。SSH 断开后远端进程是否退出，取决于服务器配置及进程行为。

### 连接与分组

左侧“添加连接”和“添加分组”用于保存配置，创建不会自动连接。点击已保存连接后填写认证信息；搜索分组时包含其后代，搜索连接时保留所属分组。

最多保存 500 项资产、8 层分组。配置保存在当前站点的 `localStorage`，不包含密码、私钥或口令；不同浏览器和端口不共享配置。浏览器数据清理会移除这些配置，当前没有导出功能。

## 开发与验证

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动开发页面和本机会话服务 |
| `npm run check` | 执行 TypeScript 和 ESLint 检查 |
| `npm test` | 执行模型、协议和会话集成测试 |
| `npm run build` | 类型检查并构建前端到 `dist/` |
| `npm run preview` | 在 `http://127.0.0.1:4173/` 预览构建并提供会话服务 |

`dist/` 仅包含前端，静态托管不能提供终端功能。开发与预览均需要完整仓库和 Node.js 依赖。`node-pty` 含原生模块，安装与测试要求见 [开发指南](docs/development.md)。

## 项目结构

```text
src/                  浏览器界面、共享协议、资产与标签模型
server/               WebSocket 服务、本地 PTY 子进程、SSH 与主机指纹
tests/                Node.js 自动化测试
docs/                 开发指南与项目维护上下文
licenses/             第三方许可原文
.agents/skills/       项目协作技能
vite.config.ts        开发与预览服务配置
components.json       shadcn/ui 组件配置
package-lock.json     npm 依赖锁文件
```

前端通过同源 WebSocket 与本机服务通信。本地终端在独立子进程中运行 `node-pty`，远端终端通过 `ssh2` 建立独立连接。数据流、资源限制和测试方法见 [开发指南](docs/development.md)。
