# NovaTerminal

本地运行的 SSH 与终端客户端，采用 React、TypeScript 和 shadcn/ui 构建。

项目处于开发阶段，提供 Electron 桌面应用。Windows 支持构建可运行目录包；macOS 和 Linux 尚未验证。当前没有安装器、代码签名或自动更新。

## 功能

- **独立终端**：本地 Shell 与 SSH 共用多标签工作区，默认最多 4 个标签，可设置为 1–8 个；切换保留会话和输出，支持关闭确认和断开后的显式重连。
- **SSH 直连**：支持密码、私钥及加密私钥认证；首次连接需确认 SHA-256 主机指纹，已记录的指纹变化时拒绝连接。
- **连接管理**：添加 SSH 连接、本地目录连接与嵌套分组，支持跨分组拖拽、重命名、移动和删除；按名称、目录、主机、端口或用户名搜索。公开配置及分组展开状态保存在本机，认证凭据由系统安全存储单独加密保存。
- **终端交互**：支持 Unicode、ANSI、有界粘贴、右键菜单、缓冲区搜索、http/https 链接及尺寸同步；主题、字体、光标和滚动缓冲可保存设置。

当前不支持跳板机、SSH Agent、交互式多因素认证、文件传输或远端监控。连接配置支持通过右键菜单编辑，并可导入 / 导出不含认证信息的 JSON 文件。

## 快速开始

环境要求：Node.js `>=24.19.0 <25`、npm `>=11.19.1 <12`。

```sh
npm ci
npm run dev
```

命令会启动桌面窗口，开发页面使用 `127.0.0.1:5180`。首次启动需要下载 Electron 运行时。修改主进程或 preload 后需重启开发命令，前端支持热更新。

桌面终端具有当前系统用户的 Shell 权限，通过受限 IPC 访问独立会话进程。Vite 仅用于桌面内的开发热更新，不提供独立浏览器终端服务；正式应用不监听 HTTP / WebSocket。完整边界见 [安全说明](SECURITY.md)。

### 本地终端

点击右上角“新建本地终端”。Windows 启动不加载用户 profile 的 PowerShell；macOS / Linux 使用环境变量 `SHELL` 指定的 Shell，未设置时使用 `/bin/sh`。初始工作目录为用户主目录。

点击左侧“添加本地连接”，在系统目录选择器中选择起始目录，保存到资产列表并打开终端。取消选择不会创建资产或会话；之后双击该资产即可从同一目录新建独立终端。目录不存在或无权访问时显示错误，不会改用其他目录。

会话标签可拖动调整左右顺序，也可聚焦标签后按 Ctrl+Shift+←/→ 移动；顺序保留在当前工作区，移动不重建会话。默认关闭活动会话或退出应用时需要确认，取消保留连接。关闭标签会移除对应输出；Shell 自行退出后保留标签供查看，可点击“重新连接”，在同一标签创建新会话并清空旧输出，不重放命令。SSH 重连读取当前保存的认证；资产已删除或端点已变更时，应重新打开资产。刷新页面或退出应用会断开会话，标签和终端输出不持久化。

### 设置与终端操作

顶栏“设置”打开独立设置页面，左侧按外观、终端、会话分类，右侧保留主题、字体与字号、行高、滚动缓冲、光标，以及复制、粘贴与关闭确认等选项。分类切换保留未保存的修改；点击“保存设置”后应用并返回工作区，“返回应用”、Esc 或“取消”均丢弃未保存修改。设置期间终端会话保持连接并继续接收输出，保存后外观应用到已有终端。设置保存在用户数据目录的 `settings/desktop.json`，开发模式使用 `settings/development.json`；损坏时提示恢复默认并尝试保留备份。

Shell 和默认目录只影响新会话，本地连接自带目录优先。Windows 可选默认 PowerShell、PowerShell 7（标准安装目录）、cmd 和 WSL 默认发行版；macOS / Linux 可选相应平台的 Shell。不可用时明确报错，不自动回退。降低会话上限不会终止已有会话，已结束标签仍占标签名额。

| 操作 | Windows / Linux | macOS |
| --- | --- | --- |
| 新建 / 关闭标签 | Ctrl+Shift+T / Ctrl+Shift+W | Cmd+T / Cmd+W |
| 前后切换标签 | Ctrl+Tab / Ctrl+Shift+Tab | Ctrl+Tab / Ctrl+Shift+Tab |
| 选择第 1–8 个标签 | Ctrl+1…8 | Cmd+1…8 |
| 设置 / 搜索 | Ctrl+, / Ctrl+F | Cmd+, / Cmd+F |
| 复制 / 粘贴 | Ctrl+Shift+C / Ctrl+Shift+V | Cmd+C / Cmd+V |

新建、关闭、切换标签及打开设置的工作区快捷键，在已有标签时仅于终端内容区获得焦点后生效；工作区为空时也可在非输入控件上使用。这些快捷键避开表单、弹窗、右键菜单及输入法合成过程。

Windows / Linux 的 Ctrl+C 在有选区时复制，没有选区时交给 Shell。右键菜单提供复制、粘贴、全选、清屏和搜索；清屏清理本地显示与选区，不发送远端命令。复制最多 1,048,576 个 UTF-16 单元，粘贴最多 65,536 个；超限会提示，不因此关闭会话。输入还受编码后的待发送缓冲限制，控制字符较多时可能提前达到上限；界面会整次拒绝，不发送部分内容。可开启选中即复制和多行粘贴确认，确认框只显示行数与长度。

搜索支持大小写和正则、Enter / Shift+Enter 前后查找、Esc 关闭，选中并滚动到当前匹配项，不显示全部匹配高亮。正则超时会提示简化表达式，缓冲区过大时提示缩小回滚行数，之后可继续搜索。仅 http/https 链接可交给系统浏览器；启用终端鼠标报告时需按 Ctrl / Cmd 点击。

### SSH 连接

1. 点击左侧“添加连接”，填写名称、主机、端口和用户名，选择所属分组（默认为“未分组”）。主机只填写域名或 IP，不包含 `ssh://`、用户名或路径。
2. 选择密码认证，或粘贴完整私钥及可选口令，点击“保存并连接”；也可选择“仅保存”，留待以后连接。两种方式均需填写认证信息，由本机系统安全存储加密保存，后续及重启后连接不再重复填写。系统安全存储不可用时会提示保存失败，不降级为明文。
3. 首次连接时，通过可信渠道向服务器管理员核对 SHA-256 指纹，再选择“信任并连接”。
4. 连接成功后在对应标签操作，连接状态与 Shell 信息显示在底部状态栏。

指纹变化或记录无法安全读写时连接会被阻止。记录位置与主机密钥变更处理见 [SSH 主机信任](SECURITY.md#ssh-主机信任)。SSH 断开后远端进程是否退出，取决于服务器配置及进程行为。

### 连接与分组

左侧“添加连接”统一管理 SSH 新建与认证，工具栏入口默认选择“未分组”，右键分组后选择“添加连接”则默认选择该分组，均可手动调整。“未分组”表示连接不归属任何分组，不会创建同名分组或容器：这些 SSH 和本地连接直接显示在资产列表顶层，排在顶层分组文件夹之后，同类按创建顺序排列。“添加分组”默认选择当前层级；点击列表空白处可回到顶层。

单击资产树中的连接仅更新当前分组层级，不打开终端或弹窗。双击 SSH 或本地连接直接打开终端，SSH 使用创建时已保存的认证信息，不再显示认证弹窗；键盘聚焦连接后也可按 Enter 或空格打开。分组仍单击展开 / 折叠；“添加连接”和“添加本地连接”的操作方式不变。

右键 SSH 或本地连接选择“编辑”，可修改名称、所属分组及 SSH 主机 / 端口 / 用户名或本地起始目录。SSH 默认保留现有认证，也可选择密码或私钥重新填写；修改主机、端口或用户名时必须重新填写认证。旧资产缺失认证或凭据失效时，也可通过编辑补充。已保存的密码、私钥和口令不会回填。首次主机指纹仍需核对并确认，指纹变化时拒绝连接。

SSH 连接悬停提示显示“用户名@主机”（主机可为域名或 IP），本地连接悬停提示仅显示完整起始目录路径。会话标签显示连接名称；编辑或重命名保存后，侧栏和关联标签名称同步更新。已打开的会话保持连接，新端点、认证或目录用于下次打开。

首次载入已有配置时分组默认折叠；之后恢复已保存的展开状态。新增属于当前层级的条目时，仅展开相应分支；选到其他层级新增不会展开该分支。搜索会暂时展开匹配路径，清除搜索后恢复原有状态。

将条目拖到目标分组可调整所属层级，拖到列表空白处可取消所属分组（分组本身则移至顶层）；拖到连接上表示移入该连接的所属分组。也可在连接右键菜单“移动到…”中选择“未分组”。侧边栏始终按分组优先、同类创建顺序排列，拖拽不改变这条排序规则。禁止将分组移入自身、后代或超过层级上限的位置。

右键条目可重命名、移动或删除；连接另有“编辑”，分组另有添加连接、子分组。也可聚焦条目后按 Shift+F10 打开菜单。删除分组需确认，同时移除子项；已打开的终端不受影响。配置和展开状态保存成功后才更新界面，失败时保留原数据并提示。

最多保存 500 项资产、8 层分组。配置保存在应用站点的 `localStorage`，不包含密码、私钥或口令。桌面正式资源和桌面开发页面的配置互不共享；清理对应站点存储会移除配置。

侧栏工具栏提供导入 / 导出，文件格式为 `novaterminal.connections` 版本 1，最大 1 MiB。导出仅含公开连接与分组，不含密码、私钥、口令、凭据引用、主机指纹或界面展开状态。导入先预览，再一次性合并：同一父分组下同名分组合并，同名连接并存，新条目生成新 ID，缺失父分组归到顶层；循环、超深、超量或无效字段拒绝整次导入。导入的 SSH 连接须通过“编辑”补充认证后才能打开。

## 开发与验证

| 命令 | 用途 |
| --- | --- |
| `npm run dev` | 启动 Electron 桌面窗口和前端开发服务 |
| `npm run check` | 执行 TypeScript 和 ESLint 检查 |
| `npm test` | 执行模型、协议和会话集成测试 |
| `npm run build` | 类型检查并构建前端和 Electron 入口 |
| `npm start` | 启动已构建的桌面应用 |
| `npm run package` | 构建当前平台的可运行目录包，输出到 `release/` |
| `npm run test:desktop` | 执行真实 Electron、PTY 和临时 SSH 冒烟测试 |
| `npm run test:sidebar` | 验证资产展开、拖放、右键菜单、保存失败及会话拖动 |
| `npm run test:p0` | 验证设置、搜索、剪贴板、关闭 / 重连及配置导入导出 |
| `npm run test:acceptance` | 验证拖选复制、Ctrl+C 中断、搜索、链接点击及 Shell 边界 |
| `npm run test:recovery` | 验证单实例、认证保存中断恢复和正则超时后继续使用 |
| `npm run test:package` | 在独立临时目录验证 Windows exe、PTY、主题与退出清理 |

在 Windows x64 上，运行 `npm run package` 后打开 `release/NovaTerminal-win32-x64/NovaTerminal.exe`。请保留整个目录，不能只复制可执行文件；此目录包内置 Electron / Node.js，运行时无需系统 Node.js 或 Vite。

`dist/` 仅包含桌面前端，需通过 Electron 与 preload 启动；静态托管不能提供终端功能。源码开发需要完整仓库及 Node.js 依赖。`node-pty` 含原生模块，安装与测试要求见 [开发指南](docs/development.md)。

## 项目结构

```text
src/
  main/               Electron 主进程、安全校验与会话进程入口
  preload/            受限 preload 桥接
  renderer/           页面入口及 React 界面源码
  server/             会话进程核心、PTY、SSH 与主机指纹
  shared/             跨进程协议、参数校验和资源限额
scripts/              桌面开发、构建、打包与冒烟验证
tests/                Node.js 自动化测试
docs/                 开发指南与项目维护上下文
licenses/             第三方许可原文
.agents/skills/       项目协作技能
vite.config.ts        桌面前端构建与热更新配置
components.json       shadcn/ui 组件配置
package-lock.json     npm 依赖锁文件
```

桌面前端通过 preload 与主进程通信，每个会话运行在独立 utility process 中。本地终端使用 `node-pty`，远端通过 `ssh2` 直连。窗口按钮与应用操作按钮共用 React 顶栏及主题，窗口操作经有限 IPC 调用。数据流、资源限制和测试方法见 [开发指南](docs/development.md)。
